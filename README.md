# Web Application Development - PHP & MySQL

## Course Information

- **Course title:** Web Application Development - PHP & MySQL
- **Faculty:** Computer & Information Technology
- **Instructor:** Yahye Ali Isse
- **Prerequisites:** HTML & CSS, programming fundamentals, and JavaScript

## Course Description

This course introduces dynamic, database-driven web applications using PHP and MySQL. It covers server-side programming, forms, database design, SQL, AJAX, REST APIs, authentication, security, MVC, and Laravel. Students practise these concepts in weekly exercises and a final application project.

## Course Objectives

By the end of the course, students should be able to:

- Write PHP programs using variables, data types, operators, control structures, arrays, functions, and reusable files.
- Build and validate web forms.
- Use jQuery, AJAX, and JSON to make interactive pages.
- Design relational databases and write SQL queries.
- Connect PHP to MySQL and build CRUD applications and REST APIs.
- Use cookies, sessions, authentication, authorization, and security practices.
- Organize PHP applications with MVC and work with Laravel fundamentals.

| Module | Topic | Duration | Main concepts |

## Final Project

Build a complete database-driven web application. Possible topics include a learning management, hospital, inventory, student management, booking, or e-commerce system.

The project should include user authentication, database design, CRUD operations, form validation, a responsive interface, security measures, and documentation.

## Learning Outcomes

After completing the course, students should be able to create dynamic PHP pages, manage MySQL databases, write SQL queries, build CRUD applications, process secure forms, develop REST APIs, implement authentication, apply MVC, and use Laravel fundamentals in a database-driven application.
